GOOD TO KNOW

Before you
get started.

Is YourGym available for phones?

This download is the Windows desktop version. A separate mobile-compatible release is needed for iPhone and Android.

Does the app need an internet connection?

Yes. The first launch downloads and verifies the required desktop runtime. Sign-in and shared account features also connect to YourGym's online services.

Does the website host my account or workout data?

No. This site only provides information and the Windows download. YourGym account and app data use the connected application services.
